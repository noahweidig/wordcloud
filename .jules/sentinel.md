## 2024-05-18 - Missing crossOrigin Attribute on Image Load
**Vulnerability:** The application was loading custom mask images into an HTML `<canvas>` without setting the `crossOrigin` attribute on the `Image` object. This could lead to a tainted canvas when loading images from a different origin, potentially exposing sensitive information from other origins or failing to export images correctly.
**Learning:** By default, HTML `<canvas>` elements become "tainted" if they draw an image from a different origin. Once a canvas is tainted, its data can no longer be read back via methods like `toBlob()`, `toDataURL()`, or `getImageData()`, which breaks features like exporting or reading mask pixel data.
**Prevention:** Always set `img.crossOrigin = 'anonymous'` (or the appropriate CORS setting) when creating an `Image` element that will be used to draw onto a `<canvas>` that needs to be read from later, to ensure proper CORS headers are requested and the canvas remains untainted.
